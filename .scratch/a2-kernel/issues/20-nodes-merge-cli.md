# 20 — 节点合并 CLI:把订阅里的节点搬进一份 mihomo 配置

**Status:** 设计待用户过目(未实施)

**Why now:** 19 票之后用户裁定「restful 控制 mihomo 暂时关掉、已有实例只读不接管、mihomo 让用户
自己用 agent 去配」(ADR 0013)。配置权交还给人与 agent 之后,唯一还需要工具的是那件**机械且易错**
的事:把机场订阅里几十个节点搬进一份配置。策略(规则怎么分流)是人的决定,不进这个工具。

**已定**(用户 2026-08-12 裁):**默认打到 stdout,`--out` 才落盘**。a2 不动用户的配置文件,除非人显式指路。

## 形状

```
a2 [--json] nodes merge --from <源> [--from <源2>…] [--in <基底>] [--out <路径>]
                        [--group <名字>[:select|url-test]] [--prefix <前缀>]
                        [--on-conflict fail|rename|skip] [--no-check]
a2 [--json] nodes list  --from <源>          # 只看有什么,不合并
```

- `--from` 可多次。取值域与订阅同源(`http(s)://` / `file://` / 绝对路径),**上限同样 10 MiB**。
- **只取 `proxies:`**,其余段落(rules / proxy-groups / general)一概不要 —— 这是它与「订阅激活」
  的根本分别:订阅是「把整份配置换成这个」,合并是「只搬节点」。机场那份 9817 条规则里 7116 条指向
  它自己的 `🔰 选择节点`,整份搬过来等于把基底的策略掀掉。
- `--in` 基底:节点并进它的 `proxies:`,其它段落原样透传。不给 `--in` 就只输出一段 `proxies:`。

## 五条要定的

1. **命令名**:`a2 nodes`(推荐)/ `a2 config` / 挂在 `a2 proxy` 下。
2. **是不是能力**:推荐**不是** —— 它是纯文件变换,不改系统状态、不需要仲裁,而且**必须在 daemon
   没跑的时候也能用**(与 `a2 mihomo` / `a2 service` 同一条理由)。agent 靠 `--json` 拿机读输出。
3. **重名**:推荐默认 `fail`(撞名 = 两份来源对同一个名字有不同定义,静默选一个会让规则里的引用
   指向意料之外的节点;fail-closed 与全项目同口径)。`rename` 加 `#2` 后缀、`skip` 保留基底那份。
4. **要不要顺手造组**:`--group 机场` 把本次并入的节点组成一个 select 组。**默认不造** ——
   但不造的话用户拿到 46 个节点还得自己写组。倾向:提供,并在文档里推荐。
5. **要不要用 mihomo 验一遍**:并完拿 a2 手上那份二进制跑 `mihomo -t -f <输出>`。**推荐默认开**
   (有二进制可用时),验不过就整体拒绝、一个字节都不输出。`--no-check` 关掉。

## 三条已经想清楚的

- **幂等靠用法,不靠机制**:`--in` 永远指向**手写的基底**(只有自建节点 + 规则),输出是派生物。
  重跑 = 从基底重新生成。**绝不要把上次的输出当下次的基底** —— 那会让机场节点越滚越多。
  文档要把这条写在最前面。(所以不需要「来源标记 + 清理旧节点」那套机制;YAML 里也塞不下自定义
  字段 —— mihomo 对 `proxies` 条目的未知键会报错。)
- **凭据不进报文**:节点里有 UUID / password / reality 公钥。输出本身必须可用所以不脱敏,
  但**人类面与 `--json` 的摘要里只出节点数与名字**,不出任何凭据字段;`--out` 落盘权限 0600。
- **YAML 注释**:透传基底时会丢注释(行级重写保不住)。**如实写在帮助里**,不假装保得住。

## 用户那台机器的目标用法(验收场景)

手写基底 `~/.config/a2/base.yaml`:自建 VPS 节点 + `PROXY` 组 + 三条规则
(Claude → `PROXY`、其他翻墙 → `机场`、`MATCH,DIRECT`)。然后:

```
a2 nodes merge --in ~/.config/a2/base.yaml \
               --from ~/…/subscription.yaml \
               --group 机场 \
               --out ~/.config/a2/merged.yaml
```

机场换节点了就重跑同一条命令。规则一个字都不用改。
